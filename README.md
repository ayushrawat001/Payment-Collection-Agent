# Payment Collection Agent

An AI-powered voice agent for automated payment collection using Sarvam AI, FastAPI, and Silero VAD.

## Features
- Speech-to-Text (STT)
- AI-generated conversational responses
- Text-to-Speech (TTS)
- Hindi-first communication
- Voice Activity Detection (VAD)
- Interruption handling
- Response latency tracking

## Tech Stack
- Python
- FastAPI
- Sarvam AI
- Silero VAD
- PyTorch
- HTML, CSS, JavaScript

## Setup
1. Clone the repository.
2. Install dependencies using `pip install -r requirements.txt`.
3. Add your Sarvam AI API key to a `.env` file.
4. Run the FastAPI server using `uvicorn server:app --reload`.
